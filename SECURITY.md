# Security scope

This calculator accepts one bounded IPv4 CIDR string and prints address arithmetic. It makes no network requests, executes no input, writes no files and requires no credentials or elevated privileges. It does not authorize network testing or prove a network configuration is secure.

Invalid input produces a fixed error message without echoing untrusted terminal control characters. No host address list is constructed, including for `/0`. Keep those boundaries when adding features.

Report a suspected vulnerability through a private GitHub security advisory when available. If private reporting is unavailable, request a private reporting route without including sensitive details. Do not include credentials or private network data in a public issue.
